# CarBot

Discord-бот для клана: учёт машин, контракты, сборы на ВЗП и оповещения об игровых событиях
(Граффити Вар, Street Wars, Чёрный рынок, ДРОП, ВЗХ — Война за Хаммеры).

## Быстрый старт

1. Нужен Python 3.10+.
2. Скопируйте `.env.example` в `.env` и заполните `DISCORD_TOKEN`, `GUILD_ID` и ID каналов.
3. Запустите `CarBot.bat` — он создаст `.venv`, установит зависимости и запустит бота.

Вручную:

```bat
py -3 -m venv .venv
call .venv\Scripts\activate.bat
python -m pip install -r requirements.txt
python main.py
```

В Discord Developer Portal включите **Message Content Intent** и **Server Members Intent**.

## Переменные окружения (файл `.env`)

| Переменная | Обязательно | Назначение |
|---|---|---|
| `DISCORD_TOKEN` | да | токен бота |
| `GUILD_ID` | да | ID сервера — команды синхронизируются сразу |
| `CONTRACT_CHANNEL_ID` | да | канал контрактов |
| `CAR_CHANNEL_ID` | да | канал машин |
| `LOG_CHANNEL_ID` | нет | канал логов |
| `GW_CHANNEL_ID`, `STREETWARS_CHANNEL_ID`, `CHR_CHANNEL_ID`, `DROP_CHANNEL_ID`, `VZH_CHANNEL_ID` | нет | переопределение каналов событий |

## Команды

| Команда | Что делает |
|---|---|
| `/contr <название>` | создать контракт (также работает `!контракт` и `/contr` сообщением) |
| `/take <машина> <минуты>` | взять машину на 1–120 минут |
| `/free <машина>` | освободить свою машину |
| `/cars`, `/list_cars` | обновить панель / показать список |
| `/add_car`, `/remove_car`, `/rename_car` | управление автопарком |
| `/vzpgo`, `/vzp_maps` | сбор на ВЗП и карты |
| `/gw_on`, `/gw_off`, `/streetwar_on`, `/streetwar_off`, `/chr_on`, `/chr_off`, `/drop_on`, `/drop_off`, `/vzh_on`, `/vzh_off` | оповещения |
| `/streetwar_test` | проверка файлов графиток Street Wars |

## Данные

* `cars_data.json` — единственное состояние, которое переживает перезапуск: статус, кто взял
  (`user_id`), время окончания в ISO 8601 с часовым поясом. Запись атомарная: при сбое старый файл
  не повреждается.
* Контракты и сборы ВЗП хранятся в памяти и после перезапуска сбрасываются (как и раньше).

## Тесты

```bat
python -m unittest discover -s tests -v
```

Тесты офлайн: Discord не нужен, сообщения никуда не отправляются.

## Что исправлено в main.py

* Аренда машин больше не теряется: `datetime` сохранялся в JSON и `save_cars` падал, **обрезая файл**
  до 110 байт (потеря всего автопарка). Теперь ISO-строка и атомарная запись.
* Таймеры аренды привязаны к поколению: старый таймер не освобождает машину, взятую заново.
* После перезапуска таймеры восстанавливаются, просроченные аренды освобождаются.
* Освободить машину может только тот, кто её взял (сравнение по `user_id`, а не по нику).
* Панель машин: до 25 компонентов, по 5 кнопок в ряд, страницы при большом автопарке.
* ВЗП: одно активное состояние, защита от «чужого» выбора типа, старый таймер не завершает новый
  сбор, сбор завершается успешно при наборе участников, лимиты embed и компонентов соблюдены.
* Цикл оповещений запускается один раз, а не при каждом реконнекте.
* Вывод в консоль переведён в UTF-8: на Windows с кодовой страницей cp1251 бот падал на эмодзи.
* Пути к `cars_data.json`, `graffiti`, `foto`, `vzp_maps` считаются от файла бота, а не от текущей папки.
* Очистка каналов удаляет только сообщения бота и не трогает сообщения участников.
* Понятные ошибки конфигурации (`GUILD_ID`, `DISCORD_TOKEN`) и поддержка `.env`.
